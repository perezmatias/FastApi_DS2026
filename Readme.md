## 🚀 Instrucciones de Ejecución (FastAPI)

### 1. Activar el entorno virtual
Asegúrate de estar en el directorio raíz del proyecto (`fastapi_backend`) y ejecuta el comando según tu sistema operativo:

**En Linux / macOS:**
```bash
source .venv/bin/activate
```

**En Windows (terminal de VScode):**
```cmd
.venv\Scripts\activate
```

### 2. Navegar al directorio del ejercicio
Una vez activado el entorno (verás `(.venv)` en tu terminal), muévete a la carpeta del ejercicio. 

**En Linux / macOS:**
```bash
cd u_01/u1_ej_8_integrador/
```

**En Windows:**
```cmd
cd u_01\u1_ej_8_integrador\
```

### 3. Ejecutar el servidor de desarrollo
Finalmente, levanta el servidor de FastAPI indicando el nombre del archivo.

```bash
python -m fastapi dev app/main.py
```
